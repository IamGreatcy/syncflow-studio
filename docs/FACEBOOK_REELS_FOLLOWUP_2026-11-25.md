### Graph version

The same Page token and Reel node returned HTTP 200 and facebook-api-version v27.0 for every requested version from v22.0 through v27.0. Redirect following was disabled. A v22.0 Page read and App node read also returned v27.0. debug=all supplied no version explanation. /debug_token identified the token's app as 1463250842680625. Meta lists Graph v22.0 through May 20, 2027, so expiration does not explain the observation. The token app's minimum supported version or an app-side API upgrade is plausible. In that exact app's dashboard, check Settings → Advanced → Upgrade API Version, both all-call and developer/admin settings. The dashboard settings were unavailable in this audit. ## Remaining hypotheses and manual checks

1. **A post-specific Boost condition or a stale Boost status.** The Page is promotion-eligible and the affected Reel differs from all nine comparators. In Meta Business Suite → Content → Published, open this exact Reel and capture the Boost tooltip and any content-level restriction or review notice. If the tooltip still says publication failed, give Meta Support the composite Post ID, permalink, publication timestamp, and the contradictory Graph result. Ask for the exact eligibility reason.
2. **Ad account, business, or operator restrictions.** In Business Support Home, select the specific Page, business portfolio, and ad account used by the Boost UI. Verify advertising restrictions and permissions for the acting user. In Ads Manager, check the existing account's status and billing restrictions without creating anything. If an authorized ad-account ID becomes available, compare its Marketing API status and disable reason. [Meta advertising restrictions](https://en-gb.facebook.com/business/ads/review-policy-guidelines)
3. **Content eligibility or ordinary organic distribution.** Inspect Facebook Account Status and the Page's Status or Recommendations panel for the exact Page and any Reel-level notice. In Business Suite or Professional dashboard, check post-level Insights, distribution, and rights notices. The API copyright check found no matches, and the local job had AI disclosure enabled, but these facts do not establish approval under every advertising or recommendations rule. A recommendation restriction, weak initial distribution, and a post-specific promotion condition are distinct possibilities. The current evidence does not show an API publishing penalty. [Meta Recommendation Guidelines](https://about.fb.com/news/2020/08/recommendation-guidelines/) · [Meta original-content policy](https://about.fb.com/news/2026/03/rewarding-original-creators-on-facebook/amp/)

## Controlled manual versus API experiment

Run this only after an approved production release and verification of its deployed revision, live verifier route and scheduler. Keep a single active scheduler for publishing. Confirm the exact Page and review its advertising and recommendation status first. Test with new original Reels and publish each clip once. This plan does not include the affected Reel.

- Prepare 8 to 12 matched pairs of distinct original Reels as an exploratory sample. Match topic category, language, length, creative format, cover treatment, captions, rights-cleared audio, AI disclosure when applicable and encoding. Prepare the final file before route assignment. Record file hashes and verify that any automated cover processing does not change the planned treatment.
- Within each pair, randomly assign one clip to manual Facebook publishing and the other to the repaired API. Block by day and time of day. Keep the same Page, cadence, privacy and posting surface where possible. Test immediate publication as the primary comparison. Keep any native-scheduled comparison in a separate block with matched timing. Avoid extra promotion or unequal external sharing during measurement.
- At 1 hour, 4 hours, 24 hours, 72 hours and 7 days from actual publication, record method, scheduled/request/confirmation times, Video and Post IDs, publication phase and visibility, promotion eligibility and any notices, organic and paid media views, unique media viewers, total/initial/replay counts, follower breakdown and organic unique reach if available in the dashboard. Record the exact metric, period and missing responses. Measure both routes using the same endpoint and time windows.
- Compare 72-hour organic media views and unique viewers separately using paired differences, medians and ranges. Compare the promotion eligible fraction, count missing diagnostics separately and report how often either route misses the intended slot. Small samples, content differences and platform ranking variability limit causal conclusions. A repeatable difference under these controls warrants investigation with Meta using the collected IDs and receipts.
